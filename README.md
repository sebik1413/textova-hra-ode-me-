# textova-hra-ode-me

Příběhová textová hra napsaná v jazyce Python. Cílem hráče je dostat se ven z domu pomocí vybírání správných možností, aniž by postavu chytili nebo zemřela. Hra má jeden život a více různých konců podle tvých rozhodnutí.

## Jak hru spustit

1. Stáhni si soubor `textova-hra-3.ipynb` z tohoto repozitáře do počítače.
2. Otevři soubor v prostředí pro Jupyter Notebook (např. VS Code nebo JupyterLab).
3. Spusť buňku s kódem kliknutím na tlačítko **Play cell**.

## Jak se hra ovládá

* Během příběhu zadáváš na klávesnici čísla voleb (např. `1`, `2` nebo `3`) a potvrzuješ je klávesou **Enter**.
* Na konci hry napiš `ano` a stiskni **Enter**, pokud chceš hrát znovu.
